### Shell environment set up for builds. ###

Export the machine you want to build for with 'export MACHINE=<machine>'

Possible machines are:
    ov-cb2-43-rgb
    ov-cb2-57-lvds
    ov-cb2-57-lvds-ds2
    ov-cb2-7-am070-ds2
    ov-cb2-7-ch070
    ov-cb2-7-ch070-ds2
    ov-cb2-7-pq070
    ov-cb2-7-pq070-ds2
    ov-rpi4
    ov-rpi4-64

You can now run 'bitbake <target>'

Common targets are:
    openvario-image
    openvario-image-testing
